# Dados de instrução em dicionários

Como a pessoa que apresentará o projeto ainda está aprendendo Python e não estudou classes, escolhemos dicionários para representar instruções decodificadas, definições de codificação e configurações de CPI. Cada campo da instrução continua identificado pelo nome e os campos que não pertencem ao formato permanecem `None`, preservando a informação estruturada necessária à Etapa 2; em contrapartida, os módulos precisam usar os mesmos nomes de chave ao ler e alterar esses dados.
